## Build Memory

Obsidian is allowed only for per-session Sundesk build notes in the Sundesk Build History path.

This is not product data sync.

Allowed:

- What changed.
- What was tested.
- Decisions made.
- Open questions.
- Next session scope.

Stop when the build is complete.

Do not write Lindsay data, SALTXC data, real records, files, document contents, private contact data, or imported company data to Obsidian.

## Airtable Baseline

Sundesk uses Airtable's logic model as the baseline:

- Tables.
- Records.
- Fields.
- Linked records.
- Backlinks.
- Lookups.
- Rollups.
- Counts.
- Views.
- Automations.
- Interfaces.

Sundesk is not an Airtable visual clone. Daily work should stay simpler than Airtable.
